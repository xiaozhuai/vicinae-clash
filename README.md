# Clash for Vicinae

A Vicinae extension for monitoring and controlling a Clash-compatible REST API.

## Features

- Traffic and connection overview
- Proxy mode switching
- Proxy group inspection and selector switching
- Full rule list with text search
- Live connections and logs
- Multiple backend profiles with token authentication

Open **Clash Dashboard**, choose **Backends**, and add your Clash controller URL (for example,
`http://127.0.0.1:9090`) and secret.
